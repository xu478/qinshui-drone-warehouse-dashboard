# 沁水县县域集中仓储中心低空无人机智能盘点数字大屏

面向县域集中仓储中心的库内无人机创新应用展示平台。以 3268 × 1290 超宽数字大屏为基准，集中展示：

- 无人机盘点任务、覆盖率、航程与预计完成时间
- 账实一致率、差异类型、复核与闭环进度
- 库容使用率、库存结构、出入库与可用库位
- 无人机电量、链路、边缘算力与航线重规划
- 盘点效率、人工工时节省与预估损耗避免

## 在线运行

仓库根目录为 GitHub Pages 静态站点，直接打开 `index.html` 即可运行；页面数据当前为业务场景演示数据，可进一步对接 WMS、RFID、视觉识别和无人机飞控接口。

## 设计基准

- 分辨率：3268 × 1290
- 场景：县域集中仓储中心室内盘点
- 视觉：深色数字孪生、青蓝主色、橙色异常提示
- 数据原则：只保留能支持运营判断、异常闭环与价值衡量的指标
